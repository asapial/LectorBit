## Default Permission

Default LectorBit permissions for the main window

#### This default permission set includes the following:

- `allow-app-get-version`
- `allow-app-get-diagnostics`
- `allow-library-list-roots`
- `allow-library-pick-and-register-root`
- `allow-library-revoke-root`
- `allow-library-enqueue-scan`
- `allow-library-list-scan-jobs`
- `allow-library-list-media`
- `allow-planner-list-candidates`
- `allow-planner-preview`
- `allow-plan-commit`
- `allow-plan-get-routine`
